# Master Service – Marido de Aluguel (Uberaba)

Site estático em HTML, CSS e JavaScript puro. Não precisa de instalação.

## Como publicar no GitHub Pages
1. Suba todos os arquivos desta pasta na raiz do repositório.
2. No GitHub, abra Settings > Pages.
3. Em "Branch", escolha `main` e a pasta `/ (root)`, e salve.
4. O site fica no ar em alguns minutos.

## Estrutura
- `index.html`: conteúdo da página
- `style.css`: visual e animações
- `script.js`: título animado, abas, galeria, carrossel de avaliações
- `assets/`: logo e fotos dos serviços
